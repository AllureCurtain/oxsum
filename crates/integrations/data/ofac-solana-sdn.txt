# via OXSUM_SOLANA_SDN_LIST_PATH (point it at a regenerated copy of this
# format) and adds API coverage via OXSUM_SOLANA_SANCTIONS_API_KEY; the file
# is parsed at boot and a listed entry is `Flagged` without any network call.
