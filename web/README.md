# oxsum web (React dashboard)

The standalone React frontend that will replace the Topcoat pages once it
reaches parity (issue #234). Vite + React 19 + TypeScript + Tailwind v4 +
TanStack Query, talking to the same `/api/v1` REST surface — no backend
changes needed.

## Layout

- `src/api/client.ts` — fetch wrapper over the `{data}` / `{error}` envelope.
- `src/api/schema.d.ts` — generated by `openapi-typescript` from
  `crates/server/openapi.yaml`. Regenerate after any contract change:
  `npm run codegen`.
- `src/api/hooks.ts` — TanStack Query hooks over the typed surface.
- `src/components/` — app shell and primitives styled by `src/index.css`,
  which maps the DESIGN.md tokens onto Tailwind's theme (`bg-primary`,
  `text-muted`, `border-line`, `mono`, …).
- `src/pages/` — one file per dashboard page.

## Development

```bash
npm ci
npm run codegen
npm run dev          # vite dev server, proxies /api to localhost:3000
```

Start the backend separately (`cargo run -p oxsum-server` with `.env`), then
open the Vite URL — session cookies are same-origin through the proxy.

## Production

`npm run build` emits `dist/`; `crates/server/src/spa.rs` embeds it via
`rust-embed` and serves it at `/app` (client-side routes fall back to
`index.html`, hashed `assets/` get immutable caching). The Dockerfile's
`frontend` stage runs `npm ci`, `codegen` and `build`, so the release image
still ships one binary. `dist/` is git-ignored except the committed
placeholder `index.html`, which keeps the embed folder present on a fresh
checkout.
