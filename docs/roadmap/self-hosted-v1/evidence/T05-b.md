## Behavior

Current business owners issue explicitly scoped customersRead/meteringWrite grants for selected customers, with expiry up to 365 days. Random oxs-int- secrets are hashed at rest, returned once, and null on exact issuance replay. Unsupported scopes and wildcards fail closed. Current session/TOTP/context/owner checks, mutation receipts and immutable audit share issuance/revocation transactions. Captured integration principals carry private identity fields and core operations recheck current grants. Customer list/detail filtering precedes pagination.

Migration 0077 disables legacy global service credentials without rewriting their identities/hashes/history. Deployment-token minting returns 403 before body parsing; metadata/revocation remain recovery surfaces. Legacy open holds retain trusted sweeper recovery. The legacy credentials UI now explains disabled status and directs users to the owner for scoped credentials.

Metering authorizations bind credential/customer/original operation/body, owned price, discount and freeze before financial effects. Terminal bodies bind once; changed-body replay conflicts, sibling/foreign holds return 404. Credential/customer-derived hold keys also scope watch/usage identity; caller eventId remains only a settlement label. Exact replay retains original results across price changes and never recreates a closed watch row. Trusted recovery can finish previously admitted work; later revoked/expired API calls fail. Full coordinated serving operation and zero-charge admission remain T10–T13.
