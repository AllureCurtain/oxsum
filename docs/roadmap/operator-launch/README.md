# Operator launch

This stage completes the built-in operator/customer portals and scoped embedded application adoption. [#725](https://github.com/AllureCurtain/oxsum/issues/725) tracks N00–N21.

- [Accepted contract](CONTRACT.md): product defaults, work units, dependency graph and all R/J acceptance requirements.
- [Execution ledger](EXECUTION.md): authoritative task state, issue/PR/commit links, evidence, spend and concrete next actions.
- [Integration checkpoint](evidence/integration-reconciliation.md): actual merged commits, integrated CI failures and remaining software/acceptance after the initial batch.
- [Baseline evidence](evidence/baseline.md): inspected source/runtime/CI state; historical evidence is never promoted to a new candidate result.

The [self-hosted release gates](../self-hosted-v1/RELEASE-CHECKLIST.md) remain in force. No launch-complete or publication claim follows from adopting this stage.

Individual evidence files are dated development checkpoints. Their original review/pending statements remain historical; the execution ledger owns current state, and no earlier test pass certifies a changed candidate.

Screenshot, JSON, and other capture files are no longer in this tree. The markdown conclusions stay. How to read a removed capture from git history is [EVIDENCE.md](../EVIDENCE.md).
