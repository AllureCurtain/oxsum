# Code of conduct

People who use oxsum are trusting it with balances and evidence. Conversation here has to stay usable for that.

- Talk about the behavior, the evidence, and the change. Do not attack the person.
- Do not post secrets, customer data, live payment details, or a working exploit. Security reports follow [SECURITY.md](SECURITY.md).
- Disagree in the issue. Once a technical choice is made, record it in `docs/decisions.md` instead of re-litigating it on unrelated pull requests.
- Maintainers may edit or hide a comment that contains a secret, a personal attack, or data from someone else's deployment.

This applies to issues, pull requests, and any other space maintained with this repository. Reports of conduct problems go to the same security path in [SECURITY.md](SECURITY.md), with the same rule: describe the class of problem, not other people's private data.
